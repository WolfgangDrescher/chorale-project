A **group query** runs a [query](/docs/query-schema) and sorts its matches into
groups by what the score has at them, with the features its [reads](#reads)
read. Every group counts its matches and the chorales they are in, and carries
the query that finds exactly its matches, so each group opens as a search of its
own. The groups with the most matches come first.

Group queries are run on the [Grouping](/grouping) page, which shows how often
each group occurs as a chart and a table. The tables of the [lessons](/learn)
are group queries too.

```json
{
    "query": {
        "feature": "kern",
        "voices": "bass",
        "hintReduceCompound": true,
        "pattern": [
            { "!kern": "r", "hint-14": "*" }
        ]
    },
    "groupBy": [
        { "reads": [{ "feature": "hint-14" }] },
        { "reads": [{ "feature": "metweight" }] }
    ],
    "examples": { "maxCount": 0 },
    "variants": {
        "ignoreQuality": { "ignoreQuality": true }
    }
}
```

This takes every note of the bass under a note of the soprano, groups the notes
by the interval between the two within an octave, and divides each interval by
the metric weight of the bass note. The variant `ignoreQuality` counts the
intervals without their quality, a major and a minor third as one third.

| Key                           | Type   | Required | What it is                                                                                    |
|-------------------------------|--------|----------|-----------------------------------------------------------------------------------------------|
| [`query`](/docs/query-schema) | object | yes      | The query whose matches are grouped. It cannot search a set of voice pairs (`hint-**`).       |
| [`groupBy`](#groupby)         | array  | yes      | The levels of the grouping.                                                                   |
| [`examples`](#examples)       | object | no       | How many score passages each group shows.                                                     |
| [`variants`](#variants)       | object | no       | Further groupings of the same query, such as without the interval quality, to switch between. |


## `groupBy`

A list of levels. The first level sorts all matches into groups. Each further
level divides every group of the level before it into smaller groups:

```json
"groupBy": [
    { "reads": [{ "feature": "hint-14" }] },
    { "reads": [{ "feature": "metweight" }], "maxGroupCount": 2 }
]
```

This groups the matches by the interval between bass and soprano, and divides
each interval by the metric weight of the bass note, into its two largest
groups.

| Key             | Type   | Default | What it is                                                                                                               |
|-----------------|--------|---------|--------------------------------------------------------------------------------------------------------------------------|
| `reads`         | array  |         | Required. What the level reads at every match, see [`reads`](#reads). The values of all its reads together make a group. |
| `maxGroupCount` | number | all     | How many groups the level keeps, those with the most matches.                                                            |
| `minMatchCount` | number | `1`     | How many matches a group needs at least to be kept.                                                                      |

The matches of the groups a level leaves out are counted together in one row of
their own.

### `reads`

Each entry of `reads` reads one feature at every match:

```json
"reads": [{ "feature": "mint", "positions": [1, 2], "ignoreQuality": true }]
```

| Key                                | Type    | Default            | What it is                                                                                                                                                                                        |
|------------------------------------|---------|--------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `feature`                          | string  |                    | Required. What is read: [`deg`](/docs/features/deg), [`mint`](/docs/features/mint), [`metweight`](/docs/features/metweight), `duration` or a [voice pair](/docs/features/hint) such as `hint-14`. |
| `positions`                        | array   | all                | The positions of the pattern it is read at, counted from 0. A note that answers several positions is read once. A position that [repeats](/docs/repetitions) has no single value: it is not read, and naming it is refused.|
| `voice`                            | string  | the voice searched | Only with `deg`: the voice whose scale degree is read at each position, such as `"bass"`, also where it holds a note.                                                                             |
| `notesOfVoice`                     | string  |                    | Only with `mint`: the voice whose melodic intervals are read note by note in its own rhythm, such as `"bass"`, instead of at the positions.                                                       |
| `ignoreQuality`                    | boolean | `false`            | Reads an interval of `mint` or of a voice pair without its quality: `"-M2"` and `"-m2"` are both `"-2"`. A unison keeps its quality.                                                              |
| `mintAllowIntervalComplementation` | boolean | `false`            | Only with `notesOfVoice`: an interval counts as its complement, `"-P5"` as `"+P4"`, and a repeated note or an octave is left out.                                                                 |
| `categories`                       | object  |                    | Puts the values into categories, see [`categories`](#categories).                                                                                                                                 |

A value is read, reduced into one octave where the query has
[`hintReduceCompound`](/docs/options#hintreducecompound), read without its
quality where asked, and then put into its category.

#### `categories`

A read can put the values it finds into categories. This read groups the
intervals between soprano and bass into consonances and dissonances:

```json
"reads": [
    {
        "feature": "hint-14",
        "categories": {
            "perfect": ["P1", "P5", "P8"],
            "imperfect": ["m3", "M3", "m6", "M6"],
            "dissonant": "remaining"
        }
    }
]
```

A category is a list of values. The string `"remaining"` makes a category of
every value in no list, at most once. A value in no list and with no remaining
category stays itself, a group of its own. A value in two different categories
is rejected.

Where a feature has no value, there is no category either: a voice pair has no
interval while one of its voices rests. Such matches make a group of their own.
To leave them out, ask for a value in the query, such as `"hint-14": "*"`.

### Groups of several values

`categories`, `mintAllowIntervalComplementation` and `notesOfVoice` can put
different values into one group: the category `perfect` counts `P5` and `P8`,
the complement `+P4` counts `+P4` and `-P5`. The values of such a group are its
members, each with its own query, listed when the group is opened. A category
keeps its name, any other group is named after its member with the most matches.

With `notesOfVoice`, a voice that holds a note into the match or into its last
note is in the same group as one that strikes it anew. Its member shows the held
note with a tie: `‿+M2 -P5`.


## `examples`

Each group collects score passages of its matches, which are shown when the
group is opened: the first match without ornaments, then one for each kind of
ornament, each from another chorale. A group divided further, or one with
members, shows a passage of each of its groups or members instead. An ornament
is a note on an unclassified beat, see
[`metweightSkipUnclassified`](/docs/options#metweightskipunclassified).

`examples` sets how many passages a group shows at most:

```json
"examples": { "maxCount": 3 }
```

| Key        | Type   | Default | What it is                                                                                         |
|------------|--------|---------|----------------------------------------------------------------------------------------------------|
| `maxCount` | number | all     | How many passages each group shows at most; `0` for none, which also makes the group query faster. |


## `variants`

Further groupings of the same query, each under a name of your own. A variant
adds keys to the positions of the pattern, `{}` for a position it leaves as it
is, or reads without the interval quality:

```json
{
    "query": {
        "feature": "deg",
        "voices": "soprano",
        "hintReduceCompound": true,
        "pattern": [
            { "deg": "3", "duration": "4" },
            { "deg": "2", "duration": "4" },
            { "deg": "1" }
        ]
    },
    "groupBy": [{ "reads": [{ "feature": "hint-14", "positions": [2] }] }],
    "variants": {
        "phraseEnd": { "pattern": [{}, {}, { "phrase": "end" }] },
        "phraseMiddle": { "pattern": [{}, {}, { "!phrase": "end" }] }
    }
}
```

This groups the :deg{v="3 2 1"} of the soprano by the interval to the bass at
its last note. `phraseEnd` counts only those that end a phrase, mostly on an
octave, `phraseMiddle` the others, mostly on a third.

| Key             | Type    | Default | What it is                                                                                                                                                        |
|-----------------|---------|---------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ignoreQuality` | boolean | `false` | Every read of `mint` or of a voice pair reads without the quality.                                                                                                |
| `pattern`       | array   |         | Keys added to the pattern of the query, position by position: `[{}, { "phrase": "end" }]` adds `"phrase"` to the second position. At most as long as the pattern. |

The page offers the variants above the table to switch between. The names of the
phrase positions, `phraseStart`, `phraseMiddle` and `phraseEnd`, become tabs,
the name `ignoreQuality` a switch, and any other name an entry of a select. A
tab with the switch on is the variant named after both, the phrase first and
joined by `+`, such as `phraseEnd+ignoreQuality`. Without such a variant, the
switch has no effect on that tab.
