Every chorale is analyzed once when it's loaded, producing several parallel
Humdrum spines. Each spine is a **feature** you can use as the [driving
feature](/docs/query-schema#the-driving-feature) or reference from any pattern
position:

| Feature                                 | Description                                                                          | Driving feature |
|-----------------------------------------|--------------------------------------------------------------------------------------|-----------------|
| [`kern`](/docs/features/kern)           | The notes themselves (rhythm + pitch)                                                | yes             |
| [`deg`](/docs/features/deg)             | Scale degree relative to the local key                                               | yes             |
| [`mint`](/docs/features/mint)           | Melodic interval from the previous note                                              | yes             |
| [`fb`](/docs/features/fb)               | Figured-bass harmony above the bass                                                  | yes             |
| [`metweight`](/docs/features/metweight) | Metric weight / beat strength (`"strong"`/`"half-strong"`/`"weak"`/`"unclassified"`) | yes             |
| [`hint-<pair>`](/docs/features/hint)    | Harmonic interval between one specific pair of voices                               | yes             |
| `duration`                              | Rhythmic value (Humdrum recip, tied notes combined, e.g. `"4"`, `"8"`)               | no              |
| `fermata`                               | Whether the note carries a fermata (`"true"`/`"false"`)                              | no              |
| `phrase`                                | Whether the note opens (`"start"`) or ends (`"end"`) a phrase, or the whole chorale (`"choraleStart"`/`"choraleEnd"`) | no              |
| `mode`                                  | The mode of the key the note is in (`"minor"`, `"major"`, `"dorian"`, …)             | no              |
| `key`                                   | The key the note is in, as the score writes it (`"G"`, `"e"`, `"B-"`)                | no              |
| `keyDeg`                                | The scale degree of that key in relation to the starting key (`"1"`, `"5"`, `"3-"`)  | no              |

`duration`, `fermata` and `phrase` are read directly off the underlying `**kern` token for
whichever line a driving-feature onset lands on, and `mode`, `key` and `keyDeg` from
the local key active at that note. They aren't independent spines,
so they can only appear as extra constraints inside a pattern position (see
[Checking several features at
once](/docs/patterns#checking-several-features-at-once)), never as `feature`
itself.

Each spine-backed feature has its own page with the exact token format and how
to write pattern values against it. `hint` works a bit differently from the
others: there isn't a single `hint` spine, but one per voice pair (`hint-12`,
`hint-13`, … `hint-34`), plus a `hint-<voice>` shorthand; see its own page for
the key naming rules.



## Phrases

Phrases are delimited by fermatas. `"end"` is the note that carries a fermata,
and `"start"` is the first sounding note after a fermata, so a rest in between
is skipped. The first sounding note of a voice counts as a start too, because it
opens the first phrase. A note in the middle of
a phrase is neither, so it is asked for with a negation:
`{ "!phrase": ["start", "end"] }`.



## Local key

`mode`, `key` and `keyDeg` ask for the local key active at a note:

- `mode`: `major`, `minor`, `dorian`, `phrygian`, `lydian`, `mixolydian` or
  `locrian`.
- `key`: the key as the score writes it, `"E-"` is E-flat major and `"f#"` is
  F-sharp minor.
- `keyDeg`: the scale degree of the key in relation to the starting key, written
  like a [`deg`](/docs/features/deg) value. In a chorale in D major,
  `{ "keyDeg": "5", "mode": "major" }` finds the passages modulated to A major.

A Picardy third at the end of a phrase:

```json
{
    "feature": "deg",
    "pattern": [{ "deg": "3+", "mode": "minor", "phrase": "end" }]
}
```
