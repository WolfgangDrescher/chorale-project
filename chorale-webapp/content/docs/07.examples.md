A collection of complete, working queries for common analytical questions. Copy
one, swap out the figures/degrees that matter for your own question, and run it
across the corpus.



## Cadential soprano descent, quarter notes only, landing on a fermata

A stepwise scale-degree descent restricted to the cantus firmus into the first
scale degree, where the cantizans may be evaded to the 3rd scale degree,
restricted to quarter notes and requiring a fermata on the final note:

```json
{
    "feature": "deg",
    "voices": "soprano",
    "pattern": [
        { "deg": "3", "duration": "4" },
        { "deg": "2", "duration": "4" },
        { "deg": ["1", "3"], "duration": "*", "fermata": true }
    ]
}
```



## Cadential soprano descent, but only where the bass has its own 3-4-5-1 line underneath

The same soprano descent as above, now also requiring the bass to walk scale
degrees 3-4-5-1 at the same time, landing on its own fermata-marked tonic
exactly when the soprano lands on its cadence note. See
[Simultaneous](/docs/simultaneous):

```json
{
    "feature": "deg",
    "voices": "soprano",
    "pattern": [
        { "deg": "3", "duration": "4" },
        { "deg": "2", "duration": "4" },
        { "deg": ["1", "3"], "duration": "*", "fermata": true }
    ],
    "simultaneousWith": [
        {
            "feature": "deg",
            "voices": "bass",
            "pattern": [
                { "deg": "3", "duration": "8" },
                { "deg": "4", "duration": "8" },
                { "deg": "5", "duration": "4" },
                { "deg": "1", "duration": "*", "fermata": true }
            ]
        }
    ],
    "simultaneousAlignment": "start-end"
}
```



## A falling-fifths sequence in the bass, however it's voiced

Two root motions by a 5th in a row. Written literally as `-P5` twice, this only
finds the cases where the bass really does descend twice, which misses every
sequence that takes the octave transposition to stay in range and rises a 4th
instead. [`mintAllowIntervalComplementation`](/docs/options#mintallowintervalcomplementation)
covers both spellings of the same harmonic move:

```json
{
    "feature": "mint",
    "voices": "bass",
    "pattern": [
        { "mint": "-P5" },
        { "mint": "-P5" }
    ],
    "mintAllowIntervalComplementation": ["5"],
    "mintStartAtPreviousToken": true
}
```

`mintStartAtPreviousToken` makes each match start on the first note of the
sequence rather than on the note the first 5th lands on (see
[Options](/docs/options#mintstartatprevioustoken)). Add more `{ "mint": "-P5" }`
positions for longer circle-of-fifths runs, or drop the `P` to let diminished
5ths count too.



## Hidden octaves between soprano and bass

The soprano moves by any interval (skipping straight after a fermata-marked
note, to leave out phrase beginnings) into a step or leap that lands an octave
above the bass, while the bass is *also* moving in that same direction into that
same chord. See [hint](/docs/features/hint#hint-voice) and
[`hintReduceCompound`](/docs/options#hintreducecompound).

Since there's no way to ask "the bass moves in whatever direction the soprano
does" within one query, the ascending and descending case each need their own
query; combining them into a single request (see [Combining several
queries](/docs/query-schema#combining-several-queries)) returns both at once,
distinguishable by `queryId`:

```json
[
    {
        "id": "descending",
        "feature": "mint",
        "voices": "soprano",
        "hintReduceCompound": true,
        "pattern": [
            { "mint": "*", "fermata": false },
            { "mint": "-", "hint-1": "P8" }
        ],
        "simultaneousWith": [
            {
                "feature": "mint",
                "voices": "bass",
                "pattern": [
                    { "mint": "-" }
                ]
            }
        ],
        "simultaneousAlignment": "end"
    },
    {
        "id": "ascending",
        "feature": "mint",
        "voices": "soprano",
        "hintReduceCompound": true,
        "pattern": [
            { "mint": "*", "fermata": false },
            { "mint": "+", "hint-1": "P8" }
        ],
        "simultaneousWith": [
            {
                "feature": "mint",
                "voices": "bass",
                "pattern": [
                    { "mint": "+" }
                ]
            }
        ],
        "simultaneousAlignment": "end"
    }
]
```

This is the "hidden" (or "covered") octave: both outer voices approach the same
octave by similar motion rather than contrary or oblique motion. Swap `"P8"` for
`"P5"` in both entries and the same shape finds hidden 5ths instead; the bass's
own sub-pattern doesn't need to change, since it only checks direction, not
harmonic interval.



## A cadence and its ornamented versions in one query

The plain cadential formula in whichever voice: a note held for a half note's
worth, then the step down onto the fermata. Written literally this only finds
the voices that really do hold that note, which misses every version the chorale
decorates: a neighbour note, an anticipation, a passing note on the way.
[`metweightSkipUnclassified`](/docs/options#metweightskipunclassified) folds
those ornaments away, so the same pattern reaches the diminished readings too:

```json
{
    "feature": "kern",
    "voices": "all",
    "pattern": [
        { "mint": "*", "duration": "2" },
        { "mint": "-M2", "duration": "*", "fermata": true, "hint-14": "8" }
    ],
    "metweightSkipUnclassified": true,
    "durationAllowSplitNotes": true,
    "hintReduceCompound": true
}
```

`durationAllowSplitNotes` is what lets the half note also be a note the score
re-attacks (see [Options](/docs/options#durationallowsplitnotes)); with the
ornament already out of the way, a re-attack the chorale separated by a
neighbour note counts as one too. Drop it, and spell the half note out as `{
"duration": "4" }, { "mint": "P1", "duration": "4" }` instead, to see the two
halves of that note as their own positions.

The same idea applied to a bass cadence, where the ornament is a leap away and
back rather than a step:

```json
{
    "feature": "kern",
    "voices": "bass",
    "pattern": [
        { "mint": "*", "duration": "4" },
        { "mint": "+2", "duration": "4" },
        { "mint": "-P5", "duration": "*", "fermata": true }
    ],
    "mintAllowIntervalComplementation": "5",
    "metweightSkipUnclassified": true
}
```

Scale degrees 4–5–1, found both where the bass steps straight up to
the 5 and where it takes an offbeat detour down a 3rd and back up a 4th on the
way. What the ornament is shaped like never enters into it, only where it falls.
