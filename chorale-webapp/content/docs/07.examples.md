A collection of complete, working queries for common analytical questions. Copy
one, swap out the figures/degrees that matter for your own question, and run it
across the corpus.



## Cadential soprano descent, quarter notes only, landing on a fermata

A stepwise scale-degree descent restricted to the cantus firmus into the first
scale degree, where the cantizans may be evaded to the 3rd scale degree,
restricted to quarter notes and requiring a fermata on the final note:

```json
{
    "feature": "deg",
    "voices": "soprano",
    "pattern": [
        { "deg": "3", "duration": "4" },
        { "deg": "2", "duration": "4" },
        { "deg": ["1", "3"], "duration": "*", "fermata": true }
    ]
}
```



## Cadential soprano descent, but only where the bass has its own 3-4-5-1 line underneath

The same soprano descent as above, now also requiring the bass to walk scale
degrees 3-4-5-1 at the same time, landing on its own fermata-marked tonic
exactly when the soprano lands on its cadence note. See
[Simultaneous](/docs/simultaneous):

```json
{
    "feature": "deg",
    "voices": "soprano",
    "pattern": [
        { "deg": "3", "duration": "4" },
        { "deg": "2", "duration": "4" },
        { "deg": ["1", "3"], "duration": "*", "fermata": true }
    ],
    "simultaneousWith": [
        {
            "feature": "deg",
            "voices": "bass",
            "pattern": [
                { "deg": "3", "duration": "8" },
                { "deg": "4", "duration": "8" },
                { "deg": "5", "duration": "4" },
                { "deg": "1", "duration": "*", "fermata": true }
            ]
        }
    ],
    "simultaneousAlignment": "start-end"
}
```



## Hidden octaves between soprano and bass

The soprano moves by any interval (skipping straight after a fermata-marked
note, to leave out phrase beginnings) into a descending step or leap that lands
an octave above the bass, while the bass is *also* moving downward into that
same chord. See [hint](/docs/features/hint#hint-voice) and
[`hintReduceCompound`](/docs/options#hintreducecompound):

```json
{
    "feature": "mint",
    "voices": "soprano",
    "hintReduceCompound": true,
    "pattern": [
        { "mint": "*", "fermata": false },
        { "mint": "-", "hint-1": "P8" }
    ],
    "simultaneousWith": [
        {
            "feature": "mint",
            "voices": "bass",
            "pattern": [
                { "mint": "-" }
            ]
        }
    ],
    "simultaneousAlignment": "end"
}
```

This is the "hidden" (or "covered") octave: both outer voices approach the same
octave by similar motion rather than contrary or oblique motion. Swap `"P8"` for
`"P5"` and the same shape finds hidden 5ths instead; the bass's own sub-pattern
doesn't need to change, since it only checks direction, not harmonic interval.
