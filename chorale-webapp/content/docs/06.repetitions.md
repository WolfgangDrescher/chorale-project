A position matches one onset. With `repeat` it matches several onsets in a row,
and each of them has to satisfy the position:

| `repeat`                       | The position matches                                                        |
|--------------------------------|-----------------------------------------------------------------------------|
| `"*"`                          | any number of onsets, also none                                             |
| `"+"`                          | one onset or more                                                           |
| `"?"`                          | one onset or none                                                           |
| `3`                            | exactly three onsets                                                        |
| `{ "min": 2, "max": 8 }`       | from 2 to 8 onsets; without `min` from 0, without `max` with no upper limit |
| `{ "min": 2, "greedy": true }` | two onsets or more, as many as possible, see [below](#few-or-many-greedy)   |

`{ "repeat": "+", "mint": "-2" }` is one step down, or several in a row. A
position with nothing but `repeat` matches any notes: it is a gap in the
pattern. A phrase of the soprano from its first note to its fermata, however
long it is:

```json
{
    "feature": "kern",
    "voices": "soprano",
    "pattern": [
        { "phrase": "start" },
        { "repeat": "*" },
        { "phrase": "end" }
    ]
}
```

## Few or many: `greedy`

A repeat matches as few onsets as possible: it stops as soon as the rest of the
pattern matches. The gap above ends at the first fermata, so every match is one
phrase.

With `"greedy": true` a repeat matches as many onsets as possible. Sixth chords
in a row over a bass that moves by step (fauxbourdon), three or more:

```json
{
    "feature": "kern",
    "voices": "bass",
    "fbCompareExactChord": true,
    "skipOverlappingMatches": true,
    "pattern": [
        { "fb": "6 3" },
        { "repeat": { "min": 2, "greedy": true }, "fb": "6 3", "mint": ["+2", "-2"] }
    ]
}
```

Five sixth chords in a row would be found three times: from the first chord,
from the second and from the third. With
[`skipOverlappingMatches`](/docs/options#skipoverlappingmatches) only the first
of these matches is kept.

`greedy` is needed here. Nothing follows the last position that the repeat
could stop at, so it would never match more than its `min`. A query that ends on
a repeat is rejected unless that repeat has `"greedy": true`, is `"?"` or is a
fixed number.

In the middle of a pattern `greedy` decides which notes a repeat matches. A
phrase that begins and ends in the same key and leaves it in between:

```json
{
    "feature": "kern",
    "voices": "soprano",
    "pattern": [
        { "as": "$start", "phrase": "start" },
        { "repeat": "*", "!phrase": "end" },
        { "repeat": { "min": 1, "greedy": true }, "!key": "$start", "!phrase": "end" },
        { "repeat": "*", "!phrase": "end" },
        { "phrase": "end", "key": "$start" }
    ]
}
```

The middle repeat is the passage in another key. With `greedy` it matches that
passage to its end, without it only its first note. `"!phrase": "end"` keeps
the repeats inside the phrase: without it, a phrase that stays in its key would
run on into the next phrases until one of them ends in that key.

`"?"` makes a position optional. It is short for
`{ "max": 1, "greedy": true }`: the position is matched where it can be and
left out where it cannot. A cadence of the soprano from degree 2 to degree 1,
with or without an anticipation of the 1:

```json
{
    "feature": "kern",
    "voices": "soprano",
    "choraleFilter": { "ids": [8] },
    "pattern": [
        { "deg": "2" },
        { "repeat": "?", "deg": "1" },
        { "deg": "1", "phrase": "end" }
    ]
}
```

## Limiting the duration

`min` and `max` limit how many onsets a repeat matches. A repeat can also be
limited by how long these onsets last in total:

| In `repeat`                              | The repeat lasts                                                                                                              |
|------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| `"minDuration"`, `"maxDuration"`         | at least, at most a note value, written like a [`duration`](/docs/features) in Humdrum recip: `"2"` a half, `"4."` a dotted quarter |
| `"minQuarterNotes"`, `"maxQuarterNotes"` | at least, at most a number of quarter notes: `8` is two measures in 4/4                                                       |

Long phrases of the soprano, with three measures in 4/4 or more between their
first and their last note:

```json
{
    "feature": "kern",
    "voices": "soprano",
    "pattern": [
        { "phrase": "start" },
        { "repeat": { "minQuarterNotes": 12 }, "!phrase": "end" },
        { "phrase": "end" }
    ]
}
```

A quick run down in any voice, four steps or more within a half note:

```json
{
    "feature": "kern",
    "voices": "all",
    "skipOverlappingMatches": true,
    "pattern": [
        { "kern": "*" },
        { "repeat": { "min": 4, "maxDuration": "2", "greedy": true }, "mint": "-2" }
    ]
}
```

As in the run, the limits can be combined, and a repeat keeps all of them. A
repeat with `minDuration` or `minQuarterNotes` may end a pattern without
`greedy`: it goes on until it lasts long enough.

## Repeating a whole pattern: `subPattern`

`subPattern` repeats several positions as one unit: a sequence, or any figure
that comes several times in a row, without knowing how often. `min` and `max`
then count how often the whole `subPattern` comes. A sequence of the bass, down
a fourth and up a second (Romanesca), with a fifth and a third in turn between
the outer voices, at least twice:

```json
{
    "feature": "kern",
    "voices": "bass",
    "hintReduceCompound": true,
    "mintAllowIntervalComplementation": ["4", "2"],
    "skipOverlappingMatches": true,
    "pattern": [
        { "hint-14": "3" },
        {
            "repeat": { "min": 2, "greedy": true },
            "subPattern": [
                { "hint-14": "5", "mint": "-P4" },
                { "hint-14": "3", "mint": "+2" }
            ]
        }
    ]
}
```

`mint` is the step *into* a note. The first note of the sequence has no step
that belongs to it, so it stands before the `subPattern`. With
[`mintAllowIntervalComplementation`](/docs/options#mintallowintervalcomplementation),
`-P4` also finds the fifth up and `+2` the seventh down.

Only a complete `subPattern` counts. A sequence that breaks off after the
fourth down ends on the note before it. An optional position at the end takes
that last note in:

```json
{
    "feature": "kern",
    "voices": "bass",
    "hintReduceCompound": true,
    "mintAllowIntervalComplementation": ["4", "2"],
    "skipOverlappingMatches": true,
    "pattern": [
        { "hint-14": "3" },
        {
            "repeat": { "min": 2, "greedy": true },
            "subPattern": [
                { "hint-14": "5", "mint": "-P4" },
                { "hint-14": "3", "mint": "+2" }
            ]
        },
        { "repeat": "?", "hint-14": "5", "mint": "-P4" }
    ]
}
```

Keys written next to `subPattern` apply to every position inside it: with
`"mode": "minor"` next to `subPattern`, the whole sequence is in minor. A
position inside that has the same key itself, negated or not, keeps its own
value. A `subPattern` always needs a `repeat`.

## With `simultaneousWith`

With [`simultaneousAlignment`](/docs/options#simultaneousalignment) `"end"` or
`"start-end"`, the query and its [groups](/docs/simultaneous) have to end
together. Their repeats match as many onsets as that needs. Soprano and bass in
contrary motion by step, the soprano down three steps or more and the bass up:

```json
{
    "feature": "kern",
    "voices": "soprano",
    "skipOverlappingMatches": true,
    "pattern": [
        { "kern": "*" },
        { "repeat": { "min": 3, "greedy": true }, "mint": "-2" }
    ],
    "simultaneousWith": [
        {
            "feature": "kern",
            "voices": "bass",
            "pattern": [
                { "kern": "*" },
                { "repeat": "+", "mint": "+2" }
            ]
        }
    ],
    "simultaneousAlignment": "start-end"
}
```

Both runs begin together and end together, whatever the number of notes in
each. The repeat of the bass needs no `greedy`: the match of the soprano says
where it ends.

## Good to know

- A position with `repeat` counts as one position, however many onsets it
  matches: `"#3"` is the third position whether the second repeats or not.
- No position can [refer](/docs/references) to a position with `repeat` or to
  one inside a `subPattern`, by `"#2"` or by a name given with `as`. Such a
  position matches several notes, so it has no single value.
- A position with `repeat` may itself refer to an earlier position. Every note
  it matches is then compared with that position:
  `{ "repeat": "+", "kern": "#1" }` is the pitch of the first position again,
  once or several times. The positions of a `subPattern` may refer to the
  positions before the `subPattern`.
- [`everyPosition`](/docs/patterns#the-same-features-at-every-position) applies
  to every onset a repeat matches, but cannot have a `repeat` itself. Where a
  key is given more than once, the one of the position counts first, then the
  one next to `subPattern`, then the one of `everyPosition`.
- A pattern has to match at least one onset. A pattern or a `subPattern` whose
  positions may all match nothing is rejected, like
  `[{ "repeat": "*" }, { "repeat": "?" }]`.
- With [`durationAllowSplitNotes`](/docs/options#durationallowsplitnotes) or
  [`durationAllowMergedNotes`](/docs/options#durationallowmergednotes), a
  position with `repeat` cannot check `duration`.
